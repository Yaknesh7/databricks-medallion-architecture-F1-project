# Incremental Processing Framework

## Overview
The project supports incremental data processing using batch-based ingestion.

---

## Features
- Batch ID tracking
- Batch control table
- Incremental data ingestion
- Merge/Upsert logic
- Process status monitoring

---

## Workflow
1. New batch arrives
2. Batch ID generated
3. Data ingested into Bronze
4. Silver transformations applied
5. Gold layer updated
6. Batch status updated

---

## Benefits
- Reduced processing time
- Efficient resource usage
- Faster pipeline execution
- Production-style ETL design
